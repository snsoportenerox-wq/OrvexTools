🦊 OrvexTools

Herramientas para Discord, desarrolladores y estudiantes de programación.

OrvexTools es una plataforma que reúne utilidades para Discord, herramientas de desarrollo y recursos educativos para aprender programación.

✨ Características

- 🛠️ Herramientas para Discord.
- 💻 Code Playground.
- 📚 Biblioteca de lenguajes de programación.
- 🎓 Orvex Academy.
- 🌐 Interfaz adaptable a dispositivos móviles y escritorio.
- 🌍 Soporte para varios idiomas.

📚 Orvex Academy

Academia de programación con cursos organizados por niveles y más de 100 lecciones por lenguaje.

Incluye:

- Explicaciones.
- Ejercicios prácticos.
- Comprobación automática de código.
- Evaluaciones.
- Seguimiento del progreso.

💻 Code Playground

Espacio de desarrollo para escribir, ejecutar y probar proyectos de programación.

🛠️ Tecnologías

- HTML
- CSS
- JavaScript
- Node.js

🚀 Instalación

Clona el repositorio:

git clone URL_DEL_REPOSITORIO

Entra en la carpeta:

cd OrvexTools

Inicia el proyecto:

node index.js
